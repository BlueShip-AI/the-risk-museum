Neural Pricing: Data Density, Not Model Capacity, Governs When
Neural Networks Beat Parsimonious Volatility Econometrics

My neural network lost to a simple 1993 formula when data was scarce, and won when data was plentiful.

V. Dimopoulos  ·  BlueShip Research

Abstract. I test whether a neural network improves on parsimonious (few-parameter) econometric models for volatility one day ahead. A small multilayer perceptron (~2,000 parameters), forecasting the range one day ahead from a fixed set of predictor inputs plus state inputs describing dealer positioning, is evaluated over the same out-of-sample window of 1,794 days (out-of-sample: on data the model never saw) and the same pass/fail tests as its competitors. It loses significantly: the mean absolute error of the best network is 58.9 basis points (hundredths of a percentage point), against 41.2 for a combined linear forecaster of heterogeneous autoregressive (HAR) + Cboe Volatility Index (VIX) + GJR terms and 41.6 for GJR-GARCH, a generalized autoregressive conditional heteroskedasticity model of four parameters from Glosten, Jagannathan, and Runkle (1993), with a Newey–West t of −4.37 (a t-statistic, the standard measure of whether a result is distinguishable from luck) on the error differential over all 1,794 out-of-sample daily observations. The identical architecture family, applied instead to approximating the Heston (1993) pricing map from 9,000 self-generated surfaces of implied volatility, clears every pass/fail test (accuracy of 0.23 volatility points, ~45,000x speedup, correct skew). Data density, not model capacity, governs the outcome.

Keywords: neural networks, volatility forecasting, GJR-GARCH, HAR, Heston model, deep learning volatility, data efficiency, model parsimony.

1. Introduction

A prior note in this series found that GJR-GARCH, the asymmetric volatility model with four parameters from Glosten, Jagannathan, and Runkle (1993), outperformed a Markov model of my own construction that switches between states. Nonlinear interactions are precisely what a linear recursive formula cannot represent, which motivates the present question: can a neural network do better? This note, the first on neural pricing, reports two experiments run under identical out-of-sample discipline and reaches opposite verdicts.

2. Method

I trained a small multilayer perceptron (~2,000 parameters) to forecast the range one day ahead from the same set of predictor inputs as the linear models, augmented with the state inputs describing dealer positioning. Training was walk-forward (each refit uses only data available up to that date) with monthly refits, ensembles of three random seeds (networks trained from different random starting points), and early stopping (halting training when performance on held-back data stops improving), evaluated on the same out-of-sample window of 1,794 days and the same pass/fail tests applied to every other forecaster.

3. Results

3.1 Daily volatility forecasting

Table 1 reports out-of-sample mean absolute error. The network failed to win, and lost significantly: the Newey–West t-statistic (adjusted for serial correlation in the daily errors) on the error differential is −4.37. A model of roughly 2,000 parameters was beaten by one of four, on 1,794 out-of-sample daily observations. The state inputs helped the network (58.9 against 63.4 basis points), consistent with prior measurements of dealer positioning, but no adjustment rescued the architecture at this data scale. Volatility measured daily yields about 250 observations per year, which is starvation for a neural network, far too few data points to learn from, and ample for a parsimonious recursive model.

3.2 Approximating the option surface

I then applied the same architecture family to a different task: approximating the pricing map of the Heston (1993) stochastic volatility model, the function that turns the model's parameters into a surface of implied volatility (the volatility number that makes a standard option-pricing formula match a given option price), following the Deep Learning Volatility approach of Horvath, Muguruza, and Tomas (2021). Training used 9,000 surfaces of implied volatility generated by the model itself, a dense and effectively unlimited sample. Against pre-set pass/fail thresholds the approximation passed on every axis (Table 2).

4. Discussion

The architecture family was identical; the verdicts were opposite. Neural capacity is not a modular upgrade to a forecast. It adds information where data is dense and structured (an option surface is thousands of simultaneous quotes linked by arbitrage) and loses to econometrics from forty years ago where data is scarce and noisy. A neural network fitted to a single daily time series reproduces the 63.4 basis points of Table 1, not the 0.23 volatility points of Table 2.

The first run of the Heston experiment failed: every implied volatility pinned at exactly 150%, the result of a bug on one line of my own bisection code, the routine that inverts option prices back into implied volatilities. A test of the degenerate case caught it, since as volatility-of-volatility → 0 the model must recover the standard Black–Scholes option-pricing formula exactly, which the corrected code then did to four decimals. The failure was indistinguishable from a result until the test caught it.
